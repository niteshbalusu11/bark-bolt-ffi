# Native example interface

Mode: Operate. Use each platform's system type, safe-area navigation and semantic
colors. A single green tint signals actions; errors use the semantic error color.
A grouped wallet screen leads to task-specific forms, with real balance and
network state immediately visible. Avoid custom navigation, decorative charts
and synthetic wallet activity. 44pt iOS / 48dp Android minimum touch targets.
Addresses are selectable, long values wrap, and body text follows system scaling.
Both dark and light appearances use system color roles.

Accent tokens: light #006C4C, dark #70DBAF. Body and surfaces use system roles;
the accent remains legible on the corresponding backgrounds.
